# AI Player Mod (Forge 1.20.1)

Черновой Java-мод для Minecraft Forge 1.20.1, который добавляет AI-компаньона:

- ходит по миру (базовый `RandomStrollGoal`);
- пишет сообщения в чат сервера;
- хранит ограниченную память о событиях;
- обновляет простую модель «награды/ошибки»;
- отправляет запросы в DeepSeek API.

## Важно про ключ API

Ключ **нельзя** хранить в коде или коммитить в git. Вместо этого:

```bash
export DEEPSEEK_API_KEY="ваш_ключ"
```

Также есть fallback поле `apiKey` в forge-конфиге, но рекомендуется использовать только переменную окружения.

## Быстрый старт

1. Установите JDK 17.
2. Подготовьте Forge MDK (если нужно добавить wrapper):
   - положите gradle wrapper в папку проекта, или откройте как Gradle-проект в IDE.
3. Запуск клиента:

```bash
./gradlew runClient
```

## Что можно доработать

- Добавить команду спавна сущности и регистрацию атрибутов.
- Перейти с «сырого» JSON parsing на полноценный JSON parser (`Gson/Jackson`) и извлекать только `choices[0].message.content`.
- Сохранение памяти в `SavedData` между перезапусками мира.
- Более сложное обучение (Q-learning/behavior tree + reward shaping).
